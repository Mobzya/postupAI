# Ballnik / Admission Forecast

Основа Telegram-бота для оценки прогресса ЕГЭ и поступления. Выполнены этапы 0 и 1A.
Собраны реальные данные МИФИ; валидированных прогнозов нет. Состояние и ограничения:
[STAGE_1A_REPORT.md](docs/STAGE_1A_REPORT.md). Synthetic-данные и официальные тестовые
фрагменты хранятся раздельно и явно помечены.

Стек: TypeScript → Cloudflare Worker → D1; Python 3.12+ для офлайн-данных.
Node.js 24+; runtime-зависимостей нет. TypeScript и Wrangler нужны для разработки.
Для офлайн-данных: `python3 -m pip install -r requirements-data.txt`, а также
`pdftotext` из Poppler (проверено с 24.02.0). Python-парсеры не входят в Worker.

## Быстрый запуск

```bash
npm ci
npm run check
npm run db:local
cp .dev.vars.example .dev.vars
# Заполнить два независимых секрета длиной не менее 32 символов в .dev.vars.
npm run dev
```

Проверка: `curl http://localhost:8787/health`.
Без настроенных секретов webhook возвращает 503; health доступен отдельно.
Примерные локальные значения не являются боевыми секретами. `.dev.vars` исключён из Git.

## Данные МИФИ

```bash
python3 -m pipeline.mephi_pipeline build
python3 -m pipeline.mephi_pipeline validate
python3 -m pipeline.source_matrix
python3 -m pipeline.audit
```

Сбор по сети: `python3 -m pipeline.mephi_pipeline run` (использует кэш).
Явное обновление: добавить `--refresh`. URL обнаруживаются по ссылкам официальных страниц.
Не требуется браузер. Снимки лежат в `data/raw/mephi`, результаты — в `data/normalized/mephi`.
Реестр YAML 1.2 записан в JSON-совместимой форме; старый JSON-реестр оставлен для совместимости Worker.

Извлечены все 286 строк опубликованных таблиц 2015–2025 и 82 строки каталога профилей.
Это покрытие строк источника, а не доказательство полного каталога кампании.
39 распределений мест дают только кандидатов конкурсных групп; подтверждённых групп пока 0.
Все 286 исторических наблюдений сохраняют явное неустановленное сопоставление группы.

## Что работает

`GET /health`; защищённый `POST /telegram/webhook`; минимальный профиль через `/start`;
просмотр наличия профиля `/profile`; каскадное `/delete_data`; список исходных URL `/sources`.
Повторные команды изменения состояния не применяются повторно в течение срока хранения receipt.
Остальные команды объясняют, почему каталог, ввод и прогноз ещё недоступны.

`/start` создаёт профиль после явного действия пользователя. В D1 хранится HMAC-псевдоним,
версия согласия и время создания. Telegram ID используется только в памяти для ответа.
Имена, username, тексты сообщений и сканы не сохраняются.

## Что остаётся

Остаётся уточнить конкурсные группы, шесть расхождений области каталогов и программы
в кампании 2026, затем расширять сбор на остальные вузы. После аудита: прогресс ЕГЭ, кривые поступления,
сценарии, полноценный ввод профиля и достижений, сравнение и уведомления.
Публичный деплой и регистрация webhook в этом этапе не выполнялись.
