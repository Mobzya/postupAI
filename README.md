# BALLNIK / postupAI

Telegram-помощник для подготовки к ЕГЭ и исследования поступления.
Репозиторий: [Mobzya/postupAI](https://github.com/Mobzya/postupAI).
Актуальные результаты: [PROJECT_STATE](docs/PROJECT_STATE.md),
[ROADMAP](docs/ROADMAP.md), [MODEL_CARD](docs/MODEL_CARD.md).
Изменения этапов находятся в последовательных ветках/PR; main сохраняет базу 1A
до внешнего ревью. Прежняя Git-история fa93731 сохранена.

## Что доступно

Локальный [@postupAI5_bot](https://t.me/postupAI5_bot): кнопки, поиск со страницами,
карточки и сравнение программ, исторические показатели, условный расчёт балла МИФИ,
три сценария прогресса ЕГЭ. Бот работает только при активной рабочей среде.

Каталог частичный: 523 профильные записи десяти вузов и четыре маркетинговых трека
отдельно. Из профильных записей 377 — бакалавриат/специалитет, 37 — базовое высшее,
109 — с неустановленным уровнем. Наличие в реестре не подтверждает приём 2027. История: 956 наблюдений пяти вузов, разные метрики и единицы разделены.
Правила: 59 версий ограничений МИФИ 2026 по 31 направлению; БВИ/квоты/ДВИ не автоматизированы.

Сценарии ЕГЭ — открытые гипотезы без обучения и калибровки. Baseline опубликованных
порогов проверен по времени (108 прогнозов, MAE переноса около 16 баллов), но не даёт
вероятность зачисления. Синтетический Monte Carlo работает только офлайн.
Подтверждённых конкурсных групп 0; **реальные вероятности поступления недоступны**.
Профили, избранное и сохранение персональных прогнозов выключены.

## Локальный запуск

Node 24+, Python 3.12+. TypeScript Worker/D1 и Python-пайплайн сохранены.
Для проверки PDF исходного слоя и повторного извлечения нужен pdftotext (Poppler
24.02.0; Ubuntu 24.04: apt-get install poppler-utils). Офлайн replay не требует
новых сетевых запросов к вузам, но также использует этот инструмент для проверки 1A.

```bash
npm ci
python3 -m pip install -r requirements-data.txt
npm run check
python3 -m pipeline.verify_artifacts
```

Секреты TELEGRAM_BOT_TOKEN и независимый TELEGRAM_WEBHOOK_SECRET задаются в
игнорируемом .dev.vars (права 0600), по образцу .dev.vars.example. Значения не
передаются аргументами команд и не публикуются.

```bash
npm run bot:check
npm run bot:local
```

Runner проверяет имя бота и отсутствие webhook, получает обновления long polling,
передаёт их локальному workerd на loopback и отправляет ответы. Профили/D1 не нужны.
Подробности: [LOCAL_BOT](docs/LOCAL_BOT.md). Cloudflare пока отложен пользователем.

## Проверки и эксплуатация

Перед Wrangler-проверками остановите локальный runner, затем запустите его снова.

```bash
npm run quality
python3 scripts/verify_rules_import.py
python3 -m pipeline.public_backup create --directory artifacts/public-backup
python3 -m pipeline.public_backup restore --directory artifacts/public-backup --destination artifacts/restored.sqlite
```

quality: тесты TypeScript/Python, офлайн-проверка всех публичных артефактов,
Worker dry build, локальные миграции и два HTTP smoke с синтетическими сообщениями.
Повторный импорт включает предыдущие этапы. Бэкап создаётся из свежего публичного
датасета, не копирует рабочие профили, проверяет хеш/целостность/FK/числа при восстановлении.
Реальные секреты и сообщения в CI не используются, автоматического деплоя нет.
