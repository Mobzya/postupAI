# Работа над Ballnik

Прочитай README.md, docs/ARCHITECTURE.md, DATA_AUDIT.md и docs/STAGE_0_REPORT.md.
Текущее задание ограничено этапом 0. Каталог программ и модели не готовы.
Не выдавай synthetic-фикстуры и предположения за реальные сведения.
Не сохраняй токены, Telegram ID, имена или тексты сообщений в логах и fixtures.
Изменения исторических данных — только новые версии с provenance, не UPDATE.
Не смешивай категории конкурса. Не выводи вероятность без проверенного артефакта.
Перед завершением: npm run check; npm run deploy:dry; npm run db:local.
Изменения данных: python3 -m pipeline.audit, проверить DATA_AUDIT.md.
Официальные правила 2027 года нельзя выводить из правил 2026 года.
