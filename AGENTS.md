## Локальный Telegram-бот — новое задание пользователя 24.10.2026

Пользователь отдельно разрешил раннюю интеграцию бота @postupAI5_bot, затем уточнил:
пока без Cloudflare, запускать бота локально во время работы и после этапов.
Это разрешение на локальную интеграцию. Последовательность дальнейших этапов задаёт
последнее указание пользователя ниже.

- `npm run bot:check` проверяет токен и отсутствие webhook без чтения сообщений.
- `npm run bot:local` запускает long polling и локальный Worker из wrangler.bot.toml.
- При работе над проектом поддерживать этот локальный запуск, пока среда активна.
  Не запускать два poller одного бота. Перед другими Wrangler-проверками остановить
  локальный runner и после успешных проверок запустить заново.
- После этапа обновить config/bot.release.json (stage/version/review_status/review_url),
  проверить npm run check, сборку и локальный запуск, затем обновить PROJECT_STATE.
- Токен, секрет webhook, сообщения и chat/user ID не сохранять в Git, логах и fixtures.
  Секреты находятся в игнорируемом .dev.vars, доступ 0600. В argv реальные секреты не передавать.
- Ранний бот работает без D1 и сохранения профилей. PROFILE_STORAGE_ENABLED=true
  допускается только для существующих локальных синтетических тестов.
- Не удалять существующий webhook автоматически, не вызывать getUpdates при активном webhook.
- Не обещать постоянную доступность: после остановки рабочей среды бот не отвечает.
