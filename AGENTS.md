# Работа над Ballnik

Прочитай README.md, docs/ARCHITECTURE.md, DATA_AUDIT.md и docs/STAGE_0_REPORT.md.
Текущее задание ограничено этапом 1B: структура конкурсов МИФИ 2025–2026,
без моделей и расширения бота. Сначала читать docs/PROJECT_STATE.md и docs/ROADMAP.md.
Прочитай docs/STAGE_1A_REPORT.md и docs/DATA_DICTIONARY.md, если они существуют.
Различай образовательную программу, направление, конкурсную группу и распределение мест.
Кандидат группы из rowspan не является подтверждённой конкурсной группой.
Не выдавай synthetic-фикстуры и предположения за реальные сведения.
Не сохраняй токены, Telegram ID, имена или тексты сообщений в логах и fixtures.
Изменения исторических данных — только новые версии с provenance, не UPDATE.
Не смешивай категории конкурса. Не выводи вероятность без проверенного артефакта.
Перед завершением: npm run check; npm run deploy:dry; npm run db:local.
Изменения данных: python3 -m pipeline.audit, проверить DATA_AUDIT.md.
Официальные правила 2027 года нельзя выводить из правил 2026 года.

Постоянные правила пользователя (24.10.2026):
- Каждый этап заканчивается коммитом, отчётом и обновлением PROJECT_STATE.md.
  После 1B остановиться для внешней проверки; 1C автоматически не начинать.
- Сохранять существующую Git-историю и архитектуру TypeScript Worker/D1 + Python.
  Миграции 0001–0004 неизменяемы; новые структуры — только новыми миграциями.
- Статусы исследования групп: confirmed, inferred, unresolved. Старый candidate
  описывает область распределения мест; он не равен inferred.
- Не повышать статус без документального основания того же года, кампуса и категории.
  Не переносить идентичности групп между годами по совпадению кода.
- Не создавать профили поступающих и не восстанавливать личности по спискам.
- Платные сервисы требуют отдельного согласования. Тяжёлые расчёты — вне Worker.
- До публичного запуска проверить правовую схему хранения данных граждан РФ.
  HMAC идентификатора — псевдоним, не гарантия анонимности; тестировать на синтетике.
- Целевой каталог: все бакалаврские и специалитетные программы десяти вузов.
  Углублённое моделирование сначала для математики, CS, AI/ML.
- Для 1B дополнительно: python3 -m pipeline.competition_research validate;
  python3 scripts/verify_competition_import.py; npm run test:smoke.
