# Этап 2B — сценарный калькулятор прогресса ЕГЭ

Ветка stage/2b-ege-growth, база 2A 3b67b80. Реализован согласованный эвристический
этап: эмпирических траекторий школьников нет, поэтому ни один темп не объявлен нормой.

## Входы и расчёт

src/growth.ts принимает предметы, массивы датированных пробников, часы в неделю
на каждый предмет, регулярность 0–1, дату расчёта, экзамена и необязательную цель.
Три предмета первой версии: математика, информатика, русский. Последний пробник —
опорная точка; другие пробы пока диагностические и не оценивают персональный темп.
План действует с даты расчёта, не применяется задним числом к старому пробнику.

config/progress.scenarios.v1.json — версия гипотез. Прирост по диапазонам 0–60,
60–85, 85–100 интегрируется кусочно, с замедлением. Часы масштабируются квадратным
корнем, регулярность линейно; осторожный/базовый/ускоренный множители 0.55/1/1.4.
Гипотезы неопределённости включают ошибку пробника, горизонт и устаревание пробника.
Семь общих латентных узлов создают ограниченные целочисленные распределения.
Предметы имеют общий ранг шока — сильная явно выбранная зависимость, не оценка
эмпирической корреляции. Сумма не считается независимой свёрткой предметов.

Результат: центральные месячные траектории, распределения, медиана и квантили 10–90,
доля заданного распределения выше цели. Цель никак не влияет на прогноз.
Сценарная доля не названа достоверной вероятностью успеха или поступления.
Квантили не называются проверенным доверительным интервалом.

## Бот и проверка

/ege показывает три сценария без сохранения ввода. /model объясняет параметры.
Пример: /ege 2027-06-01 мат=70/6 инф=75/6 рус=65/3 цель=280 рег=0.8
Дата пробника по умолчанию сегодня; пробник=YYYY-MM-DD задаёт реальную дату.
Это не выбор точных дат ЕГЭ за пользователя: конечную дату указывает пользователь.

Проверяются нормировка, 0/100, насыщение, нулевые часы/регулярность, отсутствие роста
после даты экзамена, просроченные/будущие/невозможные даты, повтор предмета,
отсутствующие данные, неизменность распределения при смене цели и зависимая сумма.
Полный npm run check: 41 Node + 72 Python = 113 тестов. Worker dry build,
локальные миграции и synthetic HTTP smoke выполняются перед коммитом.

База не менялась; повторный импорт не нужен. Новый локальный бот использует
тот же stateless Worker, профили отключены. Гипотезы этапа 0 сохранены отдельно
как неиспользуемый архив, не перезаписаны под вид обученной модели.

## Ограничения

Нет калибровки, причинной оценки пользы часов, личной динамики, различий пробников,
реальной совместной ошибки предметов. Семь узлов дают грубые сценарные доли.
Поддержка остальных предметов требует отдельных гипотез или данных. Пользовательские
истории и добровольное исследование не запускались. Прогноз поступления недоступен.
Следующий этап — экспериментальный baseline исторических порогов 3A.
