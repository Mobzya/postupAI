## 5. Код и схема

Миграция 0005 добавляет два append-only журнала: `competition_group_assessments`
и `historical_group_assessments`. Всего 31 таблица проекта против 29 в 1A.
Legacy `candidate` сохранён для совместимости, а исследовательский статус
отдельно принимает confirmed/inferred/unresolved. Повышение по одному распределению
мест запрещено; confirmed требует официальной группы; исторические соответствия
проверяются по кампании. Полные доказательства остаются в нормализованном файле.

`pipeline.competition_research` детерминированно строит и проверяет журналы;
подмена статуса/года/доказательства не проходит replay. Импорт транзакционный,
повторный импорт не добавляет строки; конфликт payload под тем же ID не игнорируется.
В D1 не загружаются целые HTML/PDF, списки абитуриентов и тяжёлые модели.

Изменённые существующие файлы: `AGENTS.md`, `README.md`, `config/catalog_scope.json`,
`docs/ARCHITECTURE.md`, `docs/DATA_DICTIONARY.md`, `docs/local_d1_verification.json`,
`package.json`, `pipeline/import_mephi.py`.

Новые файлы: миграция 0005, `pipeline/competition_research.py`,
`scripts/verify_competition_import.py`, `tests/python/test_competition_research.py`,
два фрагмента в `tests/fixtures/mephi/1b/`,
`data/normalized/mephi/competition_research.json`,
`data/reviews/mephi_1b_findings.json`, `data/reviews/mephi_1b_sources.json`,
документы PROJECT_STATE, ROADMAP, DATA_COVERAGE, DECISIONS, MODEL_CARD,
RELEASE_CHECKLIST, этот отчёт и машинные сводки 1B.

## 7. Воспроизведение

```bash
npm ci
python3 -m pip install -r requirements-data.txt
# pdftotext из Poppler должен быть доступен
npm run check
python3 -m pipeline.competition_research build
python3 -m pipeline.competition_research validate
python3 scripts/verify_local_import.py
python3 scripts/verify_competition_import.py
npm run db:local
npm run deploy:dry
npm run test:smoke
```

Проверки выше используют исходные снимки 1A и компактные фрагменты 1B из репозитория,
не запрашивают абитуриентов и не обращаются к удалённой D1. Для повторного получения
двух страниц метаданных: `python3 -m pipeline.competition_research fetch-metadata`;
затем `replay-excerpts` требует точного совпадения родительских bytes. Если официальный
сайт изменился, нужен сохранённый снимок указанного хеша или новая ручная версия
доказательства; подмена хеша «текущим» автоматически не допускается.

## 8. Готовность для ML и следующий шаг

Данные пригодны для исследования опубликованных агрегированных порогов с оговорками.
Состав конкурса, окончательное зачисление, число/баллы БВИ и разделение категорий
не восстановлены. Распределения конкурсных баллов и достоверные вероятности строить
нельзя. Средние баллы не заменяют распределения.

Внешнее ревью должно оценить достаточность документированного результата 1B и решить
о переходе к 1C. Если появятся доступные официальные годовые перечни групп или
агрегаты зачисления, они добавляются новыми версиями без перезаписи 1A/1B.
Политика запуска и персональных данных закреплена в RELEASE_CHECKLIST; публичного
деплоя и работы с реальными пользовательскими профилями на этом этапе не было.
