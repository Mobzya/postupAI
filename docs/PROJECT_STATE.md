с `confirmed`, `inferred`, `unresolved`, миграция 0005, исследования шести случаев,
проверки неизменяемости/повторного импорта и постоянные документы проекта.

из них не следует. 120 IT-мест — общая область; 282/281 — разные строки без
установленных конкурсов; `bvi_only` не имеет числового порога.

Доступ из среды исследования вернул HTTP 451; причина и доступность из других
сетей неизвестны. Индивидуальные списки и идентификаторы не сохранены.

пробела для перехода к 1C, не объявляя структуру конкурсов известной.

или агрегированные сведения о зачислении, доступные законным способом.
