## Источники и область

- Официальная таблица МИФИ: https://admission.mephi.ru/admission/baccalaureate-and-specialty/exams/list
- Годовая привязка: https://admission.mephi.ru/content/public/uploads/documents/2026/main_doc/11._ekzameny_2026_moskva_pravka.pdf
- Индивидуальные достижения: https://admission.mephi.ru/admission/baccalaureate-and-specialty/personal-achievements
- Общий предел ИД: ранее сохранённые правила приёма МИФИ (source_id mephi-rules).

Хеши исходных снимков, даты, локаторы строк и хеши компактных представлений сохранены
в data/rules_inputs/mephi-2026.json, rules_v1/source_inventory.json и dataset.json.
Полные новые HTML/PDF не публикуются в Git. Сборка повторяется без сети:
python3 -m pipeline.academic_rules build / validate. materialize требует локальных raw.

59 версий по 31 направлению: Москва, 2026, школьный ЕГЭ, общий бюджет/платно.
Три экзаменационных слота с альтернативами, минимумы по категории, максимум ЕГЭ 100,
предел общих ИД 10. Пустые минимумы платного экономического приёма не подменены
бюджетными. Медицина 31.05.01 не включена в автоматический расчёт.

Семь видов ИД: российский документ с отличием; три знака ГТО с возрастным условием
и подтверждением; неиспользованные для особых прав дипломы ВСоШ/РСОШ.
Условие ГТО связано с возрастной группой в текущем/предыдущем году, а не датой выдачи
знака. Повтор одной семьи не суммируется; общий предел применяется после сложения.
Самодекларация не заменяет проверку диплома. Олимпиадные ИД не выдают право БВИ.
