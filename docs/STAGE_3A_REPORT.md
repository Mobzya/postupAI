# Этап 3A — baseline опубликованных порогов

Ветка stage/3a-threshold-baseline, база 2B 227ae34. Создан воспроизводимый эксперимент
исторических порогов, а не полноценная модель индивидуального поступления.

## Выборка и временная проверка

Из 956 наблюдений отобраны 382 строки ВШЭ: numeric cutoff, competition_points,
явный URL программы и код. Остальные единицы, средние, lower_bound, priority_only,
bvi_only и отсутствующие идентификаторы исключены. 144 текстовые серии по точному
ключу вуз/URL/название/код/категория/единица; это не подтверждённые конкурсные группы.

Для прогноза нужны два или три непрерывных предшествующих года. Разрыв и дубликат
годовой области прекращают цепочку. Ничего не объединяется только по коду.
Два простых метода заданы конфигом: перенос прошлого года и медиана до трёх лет.
Тестовые кампании 2023, 2024, 2025: rolling origin, каждый прогноз использует только
значения прошлых лет; при переходе к следующему году становится доступен предыдущий.
Временные split и IDs исходных/целевых наблюдений сохранены для аудита.

108 отложенных прогнозов. Перенос: MAE 15.96, RMSE 25.05, bias +7.91, медианная
абсолютная ошибка 9.5. Медиана: MAE 19.82, RMSE 33.00, bias +14.10.
Метрики по годам и категориям сохранены в evaluation.json. Основной метод задан
конфигом, автоматического подбора на тестовых результатах нет.

38 экстраполяций на 2026 — только демонстрация применения предыдущих опубликованных
порогов. История 2026 не собрана, поэтому прогноз 2027 не выдаётся.
Все новые данные производные; новые источники или неподтверждённые факты не добавлены.
Хеши dataset/config/code позволяют проверить воспроизведение.

## Реализация и проверки

pipeline/threshold_baseline.py, config/threshold.baseline.v1.json, артефакты,
src/baseline.ts и /baseline, тесты временной утечки/смешения областей/цензурирования.
python3 -m pipeline.threshold_baseline build и validate работают без сети.
Полный npm run check: 43 Node + 78 Python = 121 тест. TypeScript, сборка Worker,
локальные миграции и synthetic HTTP smoke. База данных не менялась.

## Границы

Названия/URL могут сохраняться после изменения экзаменов, групп, мест или правил.
Стабильный текстовый ключ не подтверждает стабильный механизм конкурса.
Эта ошибка предсказания порога не даёт доверительного интервала отдельной программы,
калибровки зачисления или категорий риска. Проходной балл выше 300 не обрезается
и не нормируется без доказанного числа экзаменов. Предпочтения/квоты/БВИ отсутствуют.

Полный критерий модели поступления 3A не достигнут; выполнен честный описательный
baseline с временной проверкой. 3B может реализовать только экспериментальный
симулятор и блокировку допуска до появления подтверждённых конкурсных данных.
