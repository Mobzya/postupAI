# Модели BALLNIK

## EGE scenarios v1 (2B)

Статус: сценарный калькулятор с некалиброванными гипотезами; не обученная модель.
Артефакт: config/progress.scenarios.v1.json, код src/growth.ts.
Данные обучения отсутствуют. Математика, информатика, русский; тестовые баллы 0–100.
Последний пробник + будущий план часов/регулярности → три ограниченных распределения.
Цель используется только для вычисления массы распределения, не меняет динамику.
Кусочные темпы замедляются после 60 и 85. Гипотезы неопределённости включают ошибку
измерения, горизонт и давность пробы. Общий ранг шока задаёт зависимость предметов;
независимость и эмпирическая оценка корреляции не предполагаются.

Выводы: медианы, квантили 10–90, сценарные доли. Это не проверенные вероятности,
не доверительные интервалы и не причинные оценки эффективности подготовки.
До добровольного сбора траекторий и отложенной проверки нельзя использовать их
для обещания баллов или рекомендаций с доказанной эффективностью.
См. STAGE_2B_REPORT.md. Старый progress.assumptions.json остаётся выключенным архивом.

## Поступление

Опубликованные пороги не преобразуются в вероятности зачисления. 956 наблюдений
пяти вузов включают разные единицы и категории; 382 строки — только кандидаты
для анализа порогов. Подтверждённых конкурсных совокупностей нет.
Средние, нижние границы и priority_only/bvi_only не заменяют точечный порог.
Проверенных вероятностей поступления нет; БВИ, квоты, ДВИ требуют отдельных правил.

Для допуска вероятностного артефакта нужны: годовые группы и правила, отложенные
кампании, метрики калибровки, источники и версия модели. Эти условия пока не выполнены.
