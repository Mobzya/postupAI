# Условия публичного запуска

Этап 1B: локальная разработка и синтетические профили; сервис не опубликован.

- [ ] Проверена законная схема хранения персональных профилей граждан РФ,
  включая несовершеннолетних и требования локализации; техническая схема согласована
  с результатом юридической проверки. HMAC ID не считается гарантией анонимности.
- [ ] Определены согласие, минимальные поля, удаление, ретенция и обработка инцидентов.
- [ ] Секреты Telegram и webhook созданы вне Git, независимы, безопасно установлены.
- [ ] Проверены актуальные бесплатные лимиты Workers/D1/Actions и бюджетные ограничения.
- [ ] Тяжёлые расчёты и сбор документов выполняются вне Worker.
- [ ] Проверены миграции, повторный импорт, резервирование и восстановление базы.
- [ ] Есть мониторинг ошибок без токенов, идентификаторов и текстов пользователей.
- [ ] Для каждой программы показаны источники, год, качество и ограничения данных.
- [ ] Прогнозы разрешаются только для проверенных артефактов с бэктестом и калибровкой.
- [ ] Пройден полный пользовательский сценарий и независимое ревью релиза.

Не собирать паспорта, сканы аттестатов и другие ненужные документы.
Передача кода в приватный GitHub не является публичным запуском Telegram-бота.
