# Этап 1C — воспроизводимый частичный каталог десяти вузов

Срез 24.10.2026. **Полный критерий каталога десяти вузов не выполнен:** часть
источников недоступна, знаменатель целевой полноты и условия отдельных программ
не установлены. По новому указанию пользователя эти ограничения фиксируются,
а независимая работа над следующими этапами продолжается без паузы.

## Результат

458 исходных наблюдений; 401 отображаемая запись после осторожного сопоставления
явных URL. Из них 397 профильных записей и четыре маркетинговых трека ЦУ отдельно.
Это не 397 подтверждённых вариантов зачисления: 109 записей имеют неустановленный
уровень, две относятся к базовому высшему образованию. Бакалавриат/специалитет
по данным источников установлен для 286 записей. Кампания, кампус, экзамены и
льготы подтверждены не для всех профилей, прогнозы на их основании не разрешены.

## Знаменатели и пропуски

`coverage.json` имеет десять строк, включая нулевые результаты. Полный знаменатель
программ каждого университета остаётся NULL, процент общей полноты не вычисляется.
Видимых строк источника для МИФИ — 82; для СПбГУ — 119, отдельно посчитанных по
ячейкам формы обучения PDF. Этот знаменатель относится к обработанному документу,
не к полной совокупности программ университета.

Неизвестные campus, campaign_year, degree, official_code оставлены NULL. Экзамены
имеют явный статус not_extracted. Прочерк в плане мест не заменяется нулём. Бюджетные
числа ВШЭ включают квоты и не объявляются основными конкурсными местами.
Итоговые строки «Итого»/«Всего» не являются программами и отфильтрованы.

## Происхождение и воспроизведение

- `source_inventory.json`: URL, HTTP-результаты, даты, SHA-256 исходных документов.
- `data/catalog_inputs/`: компактные структурные HTML-фрагменты, текст PDF МГУ,
  выбранные координатные блоки PDF СПбГУ. У каждого представления собственный хеш;
  parent_sha256 относится к полным исходным bytes, а не к производному фрагменту.
- `dataset.json`: отдельные факты источников с локаторами и отсутствующими полями.
- `public_index.json`: небольшой индекс для локального бота, без персональных данных.

Полные новые HTML/PDF сохранены локально в игнорируемом `data/raw/catalog/`.
На Git-фрагментах воспроизводятся нормализация, проверки и импорт без сетевых запросов.
Для повторного получения полных родительских bytes нужен официальный URL с тем же
хешем либо сохранённый снимок; изменившаяся страница требует новой версии.

Адаптеры отдельно обрабатывают четыре кампуса ВШЭ, общий план ВШЭ, профильные
карточки Иннополиса, нумерованные поля text/text2/text3 НГУ, Мытищинский филиал,
маркетинговые треки ЦУ и два формата PDF. Геометрия СПбГУ проверяется по взаимно
однозначному соответствию названий и форм обучения; изменение разметки вызывает отказ.
МФТИ/ИТМО не обходились через скрытые API или авторизацию. Списки абитуриентов не собирались.

## Схема и проверки

Миграция 0006 добавляет append-only `catalog_observations`, всего 32 таблицы проекта.
Она не заполняет строгие `program_versions` фиктивными годами и кампусами: это
стадия наблюдений перед подтверждением условий. Профили МИФИ связаны с существующими
programs через legacy_program_id. Предыдущие миграции не изменялись.

Локальная D1: 458 наблюдений после первого и второго импорта; сохранены 82 старые
программы, 286 исторических строк и 39 оценок кандидатов 1B; профилей пользователей 0.
Нарушений FK нет. Подмена нормализованного факта не проходит replay; конфликт
payload и UPDATE/DELETE отклоняются.

Проверки: `npm run check`, `python3 -m pipeline.catalog_pipeline validate`,
`python3 scripts/verify_catalog_import.py`, `npm run deploy:dry`, `npm run db:local`,
`npm run test:smoke`. Для новых форматов добавлены тесты схемы, нумерованных карточек,
агрегатных строк, прочерков/нуля, неизвестных полей, повторного импорта и provenance.

## Локальный бот и продолжение

`/programs` и `/universities` показывают покрытие. `/search` принимает вуз, название
или код; выводит до трёх записей с источниками и явными неизвестными полями.
Отсутствие результата не называется отсутствием программы в университете.
`/status` помечает каталог частичным. Никаких вероятностей и сохранения профилей.

Следующий этап 1D: собрать исторические агрегаты доступных вузов и карту пригодности
для моделирования. Пропуски 1C остаются открытыми; дальнейшая работа не объявляет
каталог полным или независимое ревью завершённым.
