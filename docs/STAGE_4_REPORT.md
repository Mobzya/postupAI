# Этап 4 — доступная часть Telegram product flow

Ветка stage/4-bot-navigation, база 3B fcd469d. Пользователь просил локальный бот без
Cloudflare. Реализован stateless-путь с кнопками; полный критерий этапа 4 (сохранение
и сравнение персональных прогнозов) не достигнут и не подменён сохранением в Telegram.

## Функции

/start → кнопка поиска → ответ на подсказку → страницы результатов → карточка →
сравнение 2–3 карточек. Отдельные кнопки: ЕГЭ, условный балл МИФИ, правила/ИД, история,
источники, статус, сведения о данных. /help объясняет команды и границы.

Reply-контекст принимается только от точного сообщения-подсказки этого бота.
Чужая подсказка не открывает сценарий. Серверные сессии и данные в D1 не создаются.
При необходимости пользователь вводит параметры одним ответом по примеру.

Поиск: 3 результата на страницу, страница=N, явная обработка неверной страницы.
Коды карточек — первые 8 hex стабильного ID источника; уникальность проверена для
всего текущего каталога. Они не объявляются идентичностями конкурсных групп.
Карточки показывают уровень/кампус/год/код, известные места и официальные URL.
Бюджет всего включает квоты, не равен местам общего конкурса. Пустые поля не становятся 0.
Сравнение сопоставляет записи источников; не ранжирует шансы и не смешивает годы молча.

Bot bridge передаёт keyboard/force_reply и отключает предпросмотр ссылок.
Токены, реальные ID и сообщения не добавлены в репозиторий или fixtures.
Полные обновления не логируются. Хранение профилей по умолчанию по-прежнему выключено.
/save и /favorites честно сообщают об отключении; правовая схема требует решения
до реального сохранения профилей, а проверенного артефакта поступления пока нет.

## Проверки

49 Node + 88 Python = 137 тестов, TypeScript, воспроизведение нормализованных данных.
Новые flow-тесты проходят /start, кнопку, доверенный reply, поиск, карточку, сравнение,
ЕГЭ и балл без доступа к D1. Проверены чужой бот/неизвестный ввод, уникальность кодов,
границы страниц, сохранение источников и отключённые профили.

scripts/smoke_bot.py проверяет тот же путь через HTTP на настоящем локальном workerd.
Используются только synthetic сообщения/ID/секрет. Параллельно с ним poller не запускается.
Прежний synthetic D1 smoke, Worker dry build и миграции сохранены.
Public index расширен уже имеющимися фактами; канонические строки данных не изменены,
новой миграции или импорта фактов нет. История/правила и подтверждения конкурсов сохранены.

Далее — CI, офлайн-воспроизводимость и локальные операционные инструменты этапа 5.
Облачный деплой отложен пользователем, а реальный пилот и персональные профили
не объявляются проведёнными по синтетическим проверкам.
