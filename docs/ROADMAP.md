# BALLNIK — дорожная карта

Основание: задание пользователя от 24.10.2026. Один репозиторий и одна история.
Каждый этап: цель → реализация → проверки → обновление PROJECT_STATE → коммит →
внешнее ревью. К следующему этапу автоматически не переходить.

Цель каталога — все доступные программы бакалавриата и специалитета МФТИ, НИУ ВШЭ,
ИТМО, МИФИ, СПбГУ, МГУ, НГУ, МГТУ им. Баумана, Иннополиса и Центрального университета.
Глубина исторических данных и моделей сначала выше для математики, CS, AI/ML.
Базовое высшее образование из прежнего конфига требует отдельного решения при 1C;
оно не подменяет согласованный охват бакалавриата/специалитета.

| Этап | Результат и критерий перехода |
| --- | --- |
| 0, 1A | Существующий Worker/D1, данные МИФИ; восстановлены из Git bundle |
| 1B | Доказательства структуры конкурсов МИФИ 2025–2026, статусы соответствий и шесть расхождений. Неизвестные группы допустимы при документированных ограничениях |
| 1C | Каталог десяти вузов: кампусы, экзамены, места; явный знаменатель полноты и отчёт о пропусках |
| 1D | Воспроизводимая история десяти вузов; хеши, дубликаты, сопоставимость и карта пригодности для ML |
| 2A | Годовые правила конкурсного балла, ИД, олимпиад, БВИ, квот, ДВИ; тестируемый расчёт |
| 2B | Сценарный прогноз ЕГЭ 0–100 по предметам, параметры-гипотезы, граничные тесты; эмпирическая калибровка позже |
| 3A | Исторический baseline с проверкой на отложенных годах и ограничениями точности |
| 3B | Вероятностная модель конкурентов, Monte Carlo, предпочтения; бэктест и калибровка |
| 4 | Telegram: путь от /start до сохранения и сравнения прогнозов, каталог, цели, достижения |
| 5 | Безопасный Cloudflare/D1, импорт, мониторинг, резервирование и CI/CD в пределах проверенных бесплатных лимитов |
| 6 | Пилот на пользователях, качество вероятностей, исправления и готовность к кампании 2027 |

Пользователь определяет приоритеты и существенные компромиссы. Разработчик готовит
код, источники, тесты, отчёты и коммиты. Приёмка каждого этапа — внешняя.
Нехватка исторического источника не должна останавливать весь проект бессрочно;
она также не даёт оснований объявлять данные известными.

Персональные прогнозы объединят распределение будущих ЕГЭ с условной моделью конкурса.
До бэктеста и калибровки сценарные доли не называются достоверными вероятностями.
