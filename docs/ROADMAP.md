# BALLNIK — дорожная карта

Основание: задание пользователя от 24.10.2026. Один репозиторий и одна история.
Каждый этап: цель → реализация → проверки → обновление PROJECT_STATE → коммит →
внешнее ревью. Обновление 24.10.2026: пользователь разрешил последовательно продолжать
этапы без остановки на подтверждение после проверок, отчёта, коммита и обновления бота.
Независимое ревью сохраняется, но не блокирует дальнейшую воспроизводимую работу.

Цель каталога — все доступные программы бакалавриата и специалитета МФТИ, НИУ ВШЭ,
ИТМО, МИФИ, СПбГУ, МГУ, НГУ, МГТУ им. Баумана, Иннополиса и Центрального университета.
Глубина исторических данных и моделей сначала выше для математики, CS, AI/ML.
Базовое высшее образование из прежнего конфига требует отдельного решения при 1C;
оно не подменяет согласованный охват бакалавриата/специалитета.

Пользователь определяет приоритеты и существенные компромиссы. Разработчик готовит
код, источники, тесты, отчёты и коммиты. Приёмка каждого этапа — внешняя.
Нехватка исторического источника не должна останавливать весь проект бессрочно;
она также не даёт оснований объявлять данные известными.

Персональные прогнозы объединят распределение будущих ЕГЭ с условной моделью конкурса.
До бэктеста и калибровки сценарные доли не называются достоверными вероятностями.

Результаты автономного цикла: 1B — документированная неопределённость конкурсов;
1C/1D — частичное покрытие; 2A — частичные годовые правила МИФИ. Переход к независимым
модулям не означает приёмку или полноту этих этапов. Реализация: git log и STAGE_*_REPORT.md.
