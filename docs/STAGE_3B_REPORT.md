# Этап 3B — лаборатория конкурса и блокировка реальных вероятностей

Ветка stage/3b-competition-simulator, база 3A cc41100. Выполнена воспроизводимая
инженерная часть. Полная приёмка 3B невозможна без подтверждённых конкурсных
совокупностей и финальных зачислений; эти данные не выдуманы.

## Алгоритм

Офлайн Python, только synthetic=true и категория general_budget. Модель задаёт
программы/места/минимумы, распределение числа конкурентов, совместный ранг их баллов,
смесь предпочтений, собственные совместные сценарии баллов и порядок предпочтений.
В каждом Monte Carlo повторе applicant-proposing deferred acceptance распределяет
места: отказавшийся участник пробует следующий вариант, одновременно удерживает
не более одного места. Баллы зависят от программы. Применяются минимумы и вместимость.

Это стабильное сопоставление лабораторной модели, не точное воспроизведение
российского зачисления с календарём согласий, БВИ, квотами, ДВИ и годовым tie-break.
Случайный tie-break и общий ранг баллов — явно заданные гипотезы.

Собственные сценарии интегрируются вместе с конкурсом. Для воспроизведения
сохраняются seed, SHA конфигурации и кода. Wilson 95% описывает лишь Monte Carlo
шум при фиксированной модели и не отражает неопределённость реального поступления.

## Проверки и применение

config/competition.synthetic.v1.json содержит исключительно вымышленные A/B.
python3 -m models.competition --trials 1000 --output artifacts/demo.json
Результат проверки: docs/stage_3b_synthetic_verification.json, synthetic=true,
deployable=false. Числа этого файла не относятся ни к одному реальному вузу.

Проверены нормировка, воспроизведение seed, нулевые места, минимумы, tie-priority,
повторные предложения после отказа, баллы по программам, отсутствие блокирующих
пар в малых задачах, аналитический пример интеграции собственного результата,
отказ реальным неподтверждённым входам и неподдерживаемым категориям.

models/calibration.py: Brier, log loss, ECE и таблица надёжности. Проверка на известных
численных примерах; это не историческая калибровка. Её метрики для реальных вузов
не публикуются, потому что нет реальных labels и подходящего временного split.

Полный npm run check: 44 Node + 87 Python = 131 тест. TypeScript, Worker dry build,
локальные миграции и synthetic HTTP smoke. Новых таблиц и источников нет.

## Допуск

pipeline.model_readiness создаёт отчёт по хешам исследования групп/истории/baseline.
Подтверждённых групп 0; годовые правила неполны, калибровки и проверенного артефакта
вероятности нет. Вывод всегда blocked. /forecast объясняет состояние и предлагает
/ege, /score, /baseline с их отдельными ограничениями. MC внутри Worker не запускается.
Далее — доступная часть этапа 4, без обхода ограничений на хранение профилей.
