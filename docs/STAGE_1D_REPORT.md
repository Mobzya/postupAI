## Важные различия источников

- ВШЭ `-*` с примечанием о приоритетном этапе включает квоты и олимпиады.
  Это **не** bvi_only. Числовой порог для такой строки не создаётся.
- ВШЭ 2015–2016 «и более» сохранено как lower_bound, не точечный исход.
  Две строки с пояснением о четырёх испытаниях остаются manual_review; не приведены к трём экзаменам.
- МИФИ: подразделения и parent_observation_id сохранены. Повторяющиеся коды
  ИНТЭЛ/ЛАПЛАЗ не потеряны и не превращены в доказанную идентичность групп разных лет.
- Баумана: минимум 163,5 не округлён. Средний показатель — сумма ЕГЭ/ВИ,
  не средний ЕГЭ одного предмета. Общая и целевая категории разделены.
- Иннополис: только одна карточка прямо называет порог ЕГЭ; единицы остальных двух
  оставлены unspecified_points. Гранты и бюджетные места разных лет не смешаны.
- НГУ: общая математическая область не разбита на вымышленные индивидуальные конкурсы.

## Происхождение и проверка

`data/history_inputs/`: структурные фрагменты таблиц, компактный агрегат НГУ,
текст PDF Мытищинского филиала, профильные признаки Иннополиса. Каждый вход имеет
собственный representation_sha256 и отдельный SHA-256 родительских bytes.
Полные новые документы локально вне Git; исходные снимки МИФИ сохранены из 1A.

`dataset.json`, `coverage.json`, `metrics.json`, `ml_readiness.json` и публичный
индекс генерируются детерминированно. В каждой строке есть источник, локатор,
год, категория, метрика, единица и статус. Списки и идентификаторы абитуриентов
не собирались, персональные профили не создавались.

```bash
python3 -m pipeline.history_dataset build
python3 -m pipeline.history_dataset validate
python3 scripts/verify_history_import.py
```

Для повторного HTTP-получения без автоматической подмены версии:

```bash
python3 -m pipeline.fetch_inventory --inventory data/normalized/history_v1/source_inventory.json --cache-root data/raw/history
```

Изменившийся хеш помечается new_snapshot_requires_review, версия набора не заменяется
молча. Происхождение ненормализованных символов/прочерков не стирается.

## ML и бот

382 строки подходят лишь как кандидаты для экспериментального анализа опубликованных
порогов при отдельном согласовании их области по годам. Для точечных целей нельзя
использовать средние, lower_bound, priority_only/bvi_only или неустановленные единицы.
Подтверждённые годовые конкурсные совокупности и окончательные распределения зачисления
не восстановлены: **калиброванные вероятности поступления не разрешены**.

В локальном боте `/history вуз программа` показывает до трёх исторических наблюдений
с единицами, категориями, источниками и предупреждением о несопоставимости.
Отсутствие результата не называется отсутствием конкурса. Хранение профилей выключено.

Следующий этап — 2A: годовые детерминированные правила. Отсутствующие сведения не
заменяются универсальной формулой или правилами другого года.
