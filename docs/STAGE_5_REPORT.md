# Этап 5 — CI и локальные операционные инструменты

Ветка stage/5-local-automation, база этапа 4 c2e6566. Выполнена доступная локальная
часть; Cloudflare отложен прямым указанием пользователя. Постоянного хостинга,
production D1, cloud-мониторинга и проверки рабочего бюджета ещё нет.

## Изменения

.github/workflows/quality.yml проверяет push/PR вручную и автоматически на стандартном
Ubuntu 24.04 runner: Node24, Python3.12, Poppler, npm ci, тесты, воспроизводимость, build/migrations,
повторный D1 import, два HTTP smoke и фактический backup/restore публичного датасета.
Права contents:read, секретов/токена бота нет, checkout credentials не сохраняет.
Actions закреплены SHA официальных релизов, найденных через GitHub API 25.10.2026;
concurrency отменяет предыдущую проверку той же ветки, timeout 15 минут.
Автодеплоя и регистрации webhook нет. Первый remote run обнаружил отсутствующий
pdftotext: установка Poppler добавлена явно, Ubuntu закреплён на 24.04 как в локальной
среде. Также отдельным коммитом включены два пропущенных provenance-артефакта.
Окончательный remote run проверяется после исправлений.

pipeline.verify_artifacts сверяет и канонические наборы, и отдельные публичные JSON
Worker: каталог, историю, годовые правила, baseline и допуск. Повреждение производного
индекса больше не может обойти проверку основного dataset.json. Проверка не пишет
файлы и не требует сети. Полные новые raw остаются отдельно; CI проверяет хеши
сохранённых компактных представлений, не обещает восстановить недоступный оригинал.

Хеш исходного кода исследовательских моделей теперь считается по bytes файла
обычным SHA-256, а не по JSON-представлению строки. Артефакты повторно построены;
факты, выборки, результаты и статусы не изменились.

scripts/check_secrets.py проверяет отслеживаемые файлы по известным форматам токенов
и запрещённым именам secrets-файлов. Выводит только пути; это ограниченная проверка,
не обещание обнаружить любой возможный секрет. Реальные credentials исключены из Git.

pipeline.public_backup создаёт свежую SQLite только из миграций и проверенных
публичных данных всех предыдущих этапов. Manifest содержит SHA файла/миграций/
датасетов, код и counts. Restore проверяет SHA, integrity, FK, counts и пустоту
всех пользовательских таблиц, фактически восстанавливает новую SQLite и проверяет
результат. Существующие каталоги/файлы не перезаписываются.
Это не backup production D1/профилей и не архив отдельных raw-источников.

README, состояние, аудит и эксплуатационные инструкции приведены к текущим функциям.
Прежние отчёты этапов и миграции не переписаны.

956 исторических нового слоя, 59 правил; профилей 0, FK нарушений нет.
Публичный backup/restore фактически выполнен, неизменность/повреждение/неверный
manifest проверены тестами. Сводка: docs/stage_5_local_verification.json.
Локальные backup-файлы в ignored artifacts/stage5-public-backup и stage5-restored.sqlite.

## Незавершённое

Полный критерий этапа 5 не выполнен: облачный deploy запрещён текущим режимом
работы пользователя, нет правовой схемы профилей и проверенного вероятностного
артефакта. Тесты на локальном workerd не измеряют CPU в Cloudflare и не доказывают
работу в бесплатных квотах под реальной нагрузкой.
Далее — техническая подготовка этапа 6; реальный пилот не объявляется проведённым.
