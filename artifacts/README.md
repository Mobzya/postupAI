# Офлайн-артефакты

Проверенных моделей нет. Каждый будущий артефакт должен содержать версии кода,
данных, конфигурации, область применимости, категорию конкурса, год,
нормированное распределение/кривую, сценарные предположения и отчёт валидации.
Синтетические артефакты не публиковать в рабочую базу.
